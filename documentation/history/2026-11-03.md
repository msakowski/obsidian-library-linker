# 2026-11-03

## Offline lookups of split parts (#341 review)

- A part split from a cross-chapter reference now carries `toChapterEnd: true` on its verse range. The offline Bible runs only these parts to the chapter's last verse; an explicit end is taken as written, so John 3:16-176 or 3:16-177 fails instead of returning 16-36. `end` keeps `MAX_VERSES_IN_CHAPTER` as the loop bound for the online fetcher, which already stops at the last verse it finds.
- A verse missing from an offline chapter is skipped only when the NWT omits it from the main text (`src/consts/omittedVerses.ts`: Matt. 17:21, 18:11, 23:14, Mark 7:16, 9:44, 9:46, 11:26, 15:28, Luke 17:36, 23:17, John 5:4, 7:53-8:11, Acts 8:37, 15:34, 24:7, 28:29, Rom. 16:24). Any other missing verse is incomplete data (the importer drops a verse whose text extraction is empty) and fails the lookup, so the configured online fallback can take over.
- Decision: a fixed list rather than data recorded by the importer. The importer cannot tell an omitted verse from a failed extraction, and a list also covers corpora imported before this change.
- Known limit: an open-ended part cannot detect a missing final verse of its chapter, since no verse counts are stored.
- Regression tests through the real in-memory repository and `OfflineBibleCitationProvider`: John 3:16-18 with verse 17 missing fails, John 3:16-176 and 3:16-177 fail, Matt. 17:20-22 skips verse 21, and the control John 3:35-4:2 resolves 3:35-36 then 4:1-2.
- Validation: zero-warning ESLint and Markdown lint, type checking, 634 Vitest tests (with the chapter-number fix below), production build, and `git diff --check` pass. The four new failure cases fail without the fix; the open-ended control passes before and after.

## Automatic quotes: created occurrence and note identity (#343 review)

- The created link is now followed by position: a `CreatedLinkTracker` keeps its document offsets, and an editor extension (`createCreatedLinkTrackingExtension`, registered with `registerEditorExtension()`) maps them through every CodeMirror change. An older mention of the same verse that moves onto the recorded line is no longer quoted. Text typed right before or after the link stays outside the tracked range.
- Before inserting, the whole created reference (`createdLink`, every comma-joined link of a multi-range reference) must still be there exactly as written, for a replacement and for an append. Removing the verse 18 link of John 3:16,18 while the lookup is pending cancels the quote.
- Without a tracked range (tracking could not start), the line-based fallback only accepts the link while its URL is on a single line of the note, ignoring its own quote right below.
- Note identity is conservative: no lookup starts when the editor's note is unknown, and nothing is written when it is unknown or different once the text arrives. The path is read first from the editor's own state (`editorInfoField`), which also covers a Canvas card that lost focus, then from the workspace.
- Added `@codemirror/state` and `@codemirror/view` as dev dependencies at the versions `obsidian` already resolved, for types; both stay external in the bundle.
- Regression tests (delayed responses, fake editor reporting each change like CodeMirror): repeated John 3:16 with a line inserted above both, a hand-made quote above, typing around the link, the verse 18 link removed (with and without tracking), unknown initial note, and a note that becomes unknown. The repeated-reference and multi-range tests fail with the previous lookup.
- Validation after merging #341: zero-warning ESLint and Markdown lint, type checking, 682 Vitest tests, production build, and `git diff --check` pass.

## Chapter number in online quotes (#341, found in Obsidian)

- Testing Matt. 3:13-4:2 online in Obsidian gave `… whom I have approved.” 4 Then Jesus was led …`: wol.jw\.org marks a chapter's first verse with the chapter number in an `a.cl` link instead of the `a.vl` verse number. The fetcher now removes both. The bug predates this branch (any online quote of a verse 1 started with the chapter number), but split quotes show it mid-text.
- Real NWT English EPUB (2026-04), imported in a test vault: the only interior gaps are John 8:1-11. Matt. 17:21, Rom. 16:24 and the other omitted verses are stored with the text `——`, so the omission list only matters for John 7:53-8:11 in that edition; it stays for editions that drop the verses.
