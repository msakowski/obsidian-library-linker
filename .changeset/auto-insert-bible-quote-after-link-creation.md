Add an opt-in "Insert quote automatically" setting, off by default, that inserts the Bible quote right after a link is created from the suggestions — silent mode, `/b` and "create link and open".

The citation is fetched in the background, so typing is never blocked. The created link is followed through edits by position, so the quote goes next to it even when the same verse is cited elsewhere in the note. Nothing is written if, by the time the text arrives, any part of the created reference was removed or changed, another note has been opened in the tab, or the note cannot be identified. A failed lookup shows a notice and leaves the note untouched. A blockquote or callout below the link only counts as its quote when it contains the same link, and a link inside a callout gets its quote after the callout. When the quote replaces a reference the cursor lands on a blank line below it, before any text that follows, and a collapsed callout template is inserted open so the quote can be read straight away — it stays foldable by hand. Quotes follow the offline Bible settings (offline first, online fallback when enabled), and an automatic quote is its own undo step. Whole-chapter links are not quoted, a reference of more than 3 chapters shows a notice instead, and when no Bible text is available at all (offline only, with no Bible imported) the failure notice is shown once per session.
